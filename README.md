# Nemesh — Recipe Site

A warm, editorial recipe website built with Next.js 14 and Strapi v5.

## Stack

- **Frontend** — Next.js 14 (App Router), MUI v6, TanStack Query
- **Backend** — Strapi v5, PostgreSQL

## Project Structure

```
nemesh/
├── client/   # Next.js frontend
└── server/   # Strapi backend
```
